## 💻 Lancer le site en local

1. Cloner le dépôt :
   ```bash
   git clone https://github.com/bruno2-stack/bruno2-stack.github.io.git
   ```
2. Ouvrir le dossier dans VS Code.
3. Ouvrir `index.html` dans le navigateur, ou utiliser l'extension **Live Server** pour un rechargement automatique.

Aucune installation ni compilation n'est nécessaire : c'est un site statique.

## 🌍 Déploiement sur GitHub Pages

1. Envoyer les fichiers à la racine du dépôt `bruno2-stack.github.io`.
2. Aller dans **Settings → Pages**.
3. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
4. Le site est publié en une à deux minutes.

## 🔧 Personnalisation

- **Couleurs** : modifier les variables au début de `style.css` (`--navy`, `--blue`, etc.).
- **Textes et projets** : modifier directement `index.html`.
- **Liens des réseaux sociaux** : chercher `s-in`, `s-gh`, `s-yt`, `s-wa` dans `index.html`.
- **Images** : remplacer les fichiers du dossier `images/` en gardant les mêmes noms.
